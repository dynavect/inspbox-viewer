# InspBox 3D review viewer

https://dynavect.github.io/inspbox-viewer/#model=models/inspbox-no-pcb.glb

Finalized faceplate, 4 November 2026. Nexus wordmark/TM at top without the stacked symbol; Vantage at bottom.
Bold labels, rounded guards and all-black faceplate markings. Matches Manufacturing Rev O / BOM Rev E.
226 components; PCB, attached display and board connectors excluded.
Door and all exported components show by default. Drag to rotate, wheel to zoom.
Front, Isometric, Faceplate and Open enclosure provide review views. Reset restores
the full model. Section, explode and measurements are for visual review;
manufacturing CAD controls fabrication.
